Singularity ships a small set of first-party apps. The aim is to cover the
everyday rather than to fill a catalog. They all build on
[libsingularity](/docs/libsingularity/), so they share the same look, the same
primitives, and your accent color.

## The lineup

- [Files](/docs/apps/files/), the file manager.
- [Edit](/docs/apps/edit/), the code and text editor.
- [Write](/docs/apps/write/), the markdown editor and PDF reader.
- [Store](/docs/apps/store/), where you find more apps.
- [Monitor](/docs/apps/monitor/), the system monitor.
- [Git](/docs/apps/git/), the git client.
- [Music](/docs/apps/music/), the music player.
- [Photos](/docs/apps/photos/), the photo viewer.
- [Videos](/docs/apps/videos/), the video player.
- [Calendar](/docs/apps/calendar/), your calendar.
- [Calculator](/docs/apps/calculator/), the calculator.
- [Leafs](/docs/apps/leafs/), the terminal.
- [Keyring](/docs/apps/keyring/), the secret store that works behind the scenes.

They are not all the same age. Some are mature, some are young. They share a
foundation, which means they improve together.
